# App Store 上架文案

App Store Connect 里逐字段粘贴。文案取自游戏内已有说法（主菜单副标题、"怎么玩"列表），
不另造卖点——与宣传片、封面保持同一套口径。

## 名称（≤30 字符）

```
老皮打僵尸
```

> 与 `CFBundleDisplayName` 一致。若该名称已被占用，退而求其次用
> `老皮打僵尸 - 塔防`，并把主菜单标题一起改（品牌名三查同步，见 AGENTS.md）。

## 副标题（≤30 字符）

```
天亮前修好家园，挡住裂隙
```

## 宣传文本（≤170 字符，可随时改，不必重新提审）


## 描述（≤4000 字符）

```
《老皮打僵尸》是一款微恐题材的塔防游戏。你可以离线单人守家，也可以联网邀请两位好友异步合作。

中间那道裂隙会不停吐出丧尸，两边分到的数量完全一样。右边是和你同阶段的异步镜像——
它不是电脑，是另一个"你"，在做和你一样的事。

动物伙伴各有所长：熊和大象挡路，豪猪反伤，狐喷火，鳗与蜂群连锁攻击。
裂隙狂潮会持续升级，家园先倒下的一方输掉。

【怎么玩】
· 一大局 12 小局，每局之间三选一拿遗物，慢慢把家堆成要塞
· 通道分三阶段打开：第 1 小局 3 路、第 2 小局 4 路、第 3 小局起全开
· 每大局开始前，从已结识动物里选 6 只出战
· 100 / 500 / 1000 分各解锁 2 只动物；1500–3500 分每 500 分再解锁 2 只，共 22 种
· 三选一遗物、伙伴改造、家园扩张，每局都不一样
· 2–6 人合作：左右两侧各三名玩家，每人守三路；各自布防，全员准备后由服务器结算并在本机回放

【特点】
· 单人模式完全离线；合作模式需要联网，不建立实时战斗连线
· 每天免费 3 大局，一次买断之后永久不限局
· 单手横屏，一局几分钟
· 单人进度保存在本机；合作房间按隐私政策中的期限自动过期

天亮了就赢。别让敲门声先到你家门口。
```

## 分类

- 主要：游戏 → 策略
- 次要：游戏 → 动作

## 年龄分级

按 App Store Connect 的问卷**如实**填写，预计落在 **13+**：

- 卡通或幻想暴力：偶尔/轻微（丧尸被击杀，无血腥）
- 恐怖/惊悚题材：偶尔/轻微（"微恐"定位，有低音量心跳与耳语氛围音）

> 不要为了上架方便而压低分级。分级不实是常见拒审原因。

## 其他必填项

| 字段 | 填法 |
| --- | --- |
| 支持 URL | 必填，可用仓库的 GitHub Pages 或任意公开页面 |
| 隐私政策 URL | 必填，内容见 `privacy-policy.md` |
| 版权 | `2026 陈赵`（与开发者账号主体一致） |
| 价格 | 免费（含一次内购） |
| 销售范围 | 按需，默认全部地区 |

## 内购

一个非消耗型项目，App Store Connect 里建好之后「内购」页面会自动显示在应用页上：

| 字段 | 值 |
| --- | --- |
| 参考名称 | Unlimited Matches |
| 产品 ID | `com.zequnhuang.zombieknock.unlimited` |
| 类型 | 非消耗型 |
| 价格 | $1.99 档 |
| 显示名称 | 无限畅玩 |
| 描述 | 一次买断：永久不限局，想玩几局玩几局。 |
| 审核备注 | 纯内购、无广告；每天 3 大局免费，买断后不限局。见 `README.md` 的变现一节 |

国内店面（版号原因）不出现内购入口，整体放行、免费不限局，所以国内渠道是小工具那套。
