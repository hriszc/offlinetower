## 1. 项目背景与设计目标

### 1.1 背景

本项目目标为复刻当前最热门的小游戏之一《赵云与阿斗》（用户侧称《阿斗与赵云》，见 §2.1 说明）。该游戏 2026 年 6 月上线抖音小游戏后快速登顶抖音小游戏双榜第一，百度百科收录为「三国题材文字合成策略塔防 IAA 小游戏」，核心玩法概括为「合成+塔防」，采用 **1V1 对称竞技模式**。其「文字合成上头 + 拼字召唤武将 + 波次防守 + 军衔成长 + 零氪也能玩」的组合已被市场验证。

### 1.2 差异化约束（硬性要求）

> **与目前游戏的区别：我们做的只有武将，没有「骑」「弓」这种普通单位。**

即：原版中「刀、弓、骑、枪」等可批量合成的普通兵种，在本项目中**整体移除**。场上存在的战斗单位只有**武将**（含技能衍生/召唤物，不再有「可批量招募的普通兵种」）。原版四兵种的战术职能由**武将职业**继承（§3.3）。

### 1.3 评审反馈要点（v1.0 已吸收）

1. **异步对战为核心模式**：用机器人模拟真人对手，比谁坚持的时间更久（对应原版 1V1 对称竞技的异步化）；
2. **保留字谜玩法**：拼凑武将姓名召唤武将（对应原版核心机制「拼凑完整姓名召唤武将」）；
3. **武将池收敛为最有名的 10 个三国人物**；
4. **参考知乎策划逆向分析**：已检索（知乎站内受反爬限制未能直接引用原文），以百度百科等权威公开资料等效覆盖，详见 §8 待确认问题 4。

### 1.4 设计目标（总览）

1. **保爽点**：保留原版「文字合成上头 + 拼字召唤 + 波次防守 + 军衔成长」的核心体验；
2. **做差异**：以「武将即单位」重构战斗深度；以「异步对战比坚持时长」重塑竞技结构；
3. **控成本**：文字/水墨风美术、小体量、单指操作，适配抖音/微信小游戏生态与 IAA/IAP 混合变现；
4. **可落地**：输出可直接转开发的系统结构、数值方向与验收标准。

## 2. 原游戏《赵云与阿斗》玩法拆解

> 说明：本拆解基于公开资料（百度百科、媒体报道、攻略站点、TapTap 论坛、B 站演示视频），确定性标注见 §2.5。当前没有可试玩的官方版本，**具体数值与部分机制存在不确定性**，下文以「确定性：高/中/低」标注。

### 2.1 产品事实与市场表现（确定性：高）

| 维度 | 事实 |
| --- | --- |
| 开发商 | 北京蜜獾工坊科技有限公司（百度百科；Google Play 包名 com.zyyad.mihuan） |
| 上线时间/平台 | 2026 年 6 月上线**抖音小游戏**（主），买量单压抖音（DataEye Adx）；后拓展微信小游戏与移动端 |
| 市场成绩 | 抖音小游戏双榜第一（北京商报）；百度百科称其「位列抖音小游戏热门榜与畅销榜前列，并在微信小游戏畅玩榜、人气榜连续多日排名靠前」 |
| 类型 | 三国题材**文字合成策略塔防 IAA 小游戏**，核心玩法「合成+塔防」 |
| 核心模式 | **1V1 对称竞技**（百度百科）：双方各自守护己方「阿斗」，谁先守不住谁输（4399：两方占据页面上下两部分，战斗直至对方保卫阿斗失败） |
| 题材包装 | 长坂坡救主：**保卫瑟瑟发抖的阿斗**；极简水墨文字风格呈现所有作战单位 |
| 变现模式 | 百度百科定位为 IAA 小游戏（广告为主）；同时登畅销榜（含内购）；整体为 IAA+IAP 混合 |

**名称说明**：公开资料中游戏官方名称为**《赵云与阿斗》**；用户侧称《阿斗与赵云》，判定为同一款游戏（名称顺序差异）。本方案统一称原版为《赵云与阿斗》，我方项目名沿用《阿斗与赵云》。

### 2.2 核心玩法循环（确定性：中-高）

```
征兵（消耗「馒头」→ 随机获得兵种字牌 / 武将碎片）
   ↓
拼字合成（字牌两两合成升级兵种；拼凑完整姓名 → 召唤武将，如 赵+云=赵云）
   ↓
布阵（部署防线，守护己方阿斗；1V1 双方各占上下半场）
   ↓
开战（波次敌军进犯，直至一方阿斗被突破即败）
   ↓
结算（按坚持波数/表现给星级 → 军衔积分）
   ↓
局外成长（武将升级、新武将解锁、军衔晋升）
   ↻ 下一局
```

关键节奏（确定性：中）：前期 1–5 波发育铺场（贴吧：先铺刀兵盾兵填格子防漏怪、优先拿「农民」道具保证馒头产出、攒字合张飞当前排）；中期 6–12 波成型（桃园羁绊等）；后期高压波 + BOSS，守不住则阿斗被破。

### 2.3 主要系统拆解

#### 2.3.1 征兵与经济系统（确定性：中-高）
- 消耗「馒头」征兵，**随机获得基础兵种字牌或武将碎片**（百度百科）——征兵是局内经济的核心出口。
- 「农民」是可携带的技能/道具，作用为加速馒头产出（游侠：技能必带农民；贴吧：优先拿农民道具保证馒头源源不断征兵）——经济类技能存在且重要。

#### 2.3.2 字谜/拼字合成系统（确定性：高）——原版最核心机制
- **文字配对升级各类士兵**（4399）：字牌两两合成升级（如刀兵字牌合成升级）。
- **拼凑完整姓名召唤武将**（百度百科）：集齐武将姓名的字牌（如「赵」「云」）→ 召唤赵云。
- 游侠攻略称核心是「文字二合一升级」；攻略出现「攒字合成张飞」等表述（贴吧）。
- 技能/道具系统中存在「招贤令」（招募）、「陨石」（全屏攻击）、「神兵符」等（游侠）。

#### 2.3.3 塔防布阵系统（确定性：中）
- 棋盘/格子制布阵；贴吧攻略强调「铺满刀兵、盾兵填满空白格子，防止漏怪」。
- 站位分工：前排肉盾（张飞）、输出（赵云）、远程补伤（黄忠）；存在「墙体」类地形机制（游侠：重甲兵诱撞墙体）。
- 存在**人口上限**概念（百度文库：「赵云与阿斗组合（4 人口）」）——上场单位数受人口约束。
- 有「堵门流」等社区打法（TapTap 帖子），说明敌方有固定出兵口/路径，存在卡位博弈。

#### 2.3.4 兵种系统（确定性：高）
- 原版存在**刀、弓、骑、枪**四类（及盾兵等）普通兵种（TapTap 帖「弓骑枪刀四兵种摆放优先级」；B 站演示「拖动 刀 弓 合成士兵」；贴吧提及刀兵、盾兵）。
- 兵种承担职能分工：枪（近战突进）、弓（远程）、刀/盾（近战抗线）、骑（机动）。

#### 2.3.5 武将系统（确定性：高，来自 CSDN 攻略）
武将即英雄单位，携带唯一技能，与兵种配合上场。已知名单与技能：

| 武将 | 定位 | 技能 | 备注 |
| --- | --- | --- | --- |
| 赵云 | 枪系核心 | 「七进七出」：直线突进群伤 | 输出+坦度，前排首选，必选主将 |
| 阿斗 | 被保护目标 | 无输出，提供全队续航与羁绊增益 | 被突破即败局 |
| 张飞 | 近战爆发 | 「大喝」：眩晕周围敌人 | 清杂兵高效、前排肉盾 |
| 黄忠 | 远程弓手 | 全屏箭矢：持续伤害+击退 | 清场利器 |
| 关羽 | 单体高伤 | 突进收割，克制精英与 BOSS | 收割型 |
| 刘备 | 范围控场 | 小幅增伤，缓解防线压力 | 桃园羁绊核心 |
| 魏延 | 纯肉前排 | 高减伤、吸引仇恨 | 保护后排 |

> 补充：百度文库提到阿斗本身具备控制能力（「阿斗也具备控制能力」），与 CSDN「阿斗无输出提供增益」不完全一致——以「阿斗为主要保护目标+辅助增益」为准，细节待试玩校准。

#### 2.3.6 技能/道具系统（确定性：中）
- 技能系统：开局选带技能（「农民」「招贤令」「陨石」为攻略推荐必带，游侠）。
- 武器/符/丹药：如赵云配点钢枪（击杀叠攻速）、龙吟亮胆枪（飞枪额外伤害）、攻速符、神兵符（金色增伤）、防御配饰；阿斗适配大补丸、续命丹（全队生命）、行军丹（体力）。

#### 2.3.7 军衔/段位系统（确定性：中-高）
- **11 级军衔**：军士 → 校尉 → 少将 → 中将 → 上将 → 大将 → 元帅 → 诸侯 → 霸主 → 君主 → 皇帝，分四梯队。
- 晋升依据：**对局积累星级**（Google Play 宣传语「从士兵到皇帝的军衔成长」）。
- 军衔同时承担「段位匹配」职能（异步对战中作为机器人强度分层依据，见 §4.3）。

#### 2.3.8 货币与运营（确定性：中）
- 局内货币：「馒头」（征兵/合成消耗）；局外货币：「蜜罐币」（B 站兑换码活动赠送 88888 蜜罐币）。
- 运营手段：兑换码、每日活动、0 点技能重置（TapTap 帖「0 点技能不重置小技巧」——技能有每日刷新/收益机制）。
- 体力限制存在（「无限体力版」流行佐证）。

### 2.4 商业化模式（确定性：中）
- IAA：百度百科明确定位为 IAA 小游戏——广告（体力恢复、复活、双倍结算、免费征兵等）为主要收入之一；「免广告版」流行佐证广告存在。
- IAP：畅销榜登顶说明内购（武将/道具/资源礼包）同样可观。
- 买量：单压抖音，素材主打「文字合成上头 + 零氪爽玩 + 长坂坡救阿斗」。

## 3. 差异化设计：只有武将的世界

### 3.1 设计原则

1. **删繁就简，武将即一切**：移除普通兵种后，战场单位 100% 是武将；征兵、合成、拼字、站位全部收敛到武将。
2. **职能不丢失**：原版四兵种（刀/弓/骑/枪）的战术职能由**武将职业体系**继承（§3.3），保留克制环与站位博弈。
3. **放大单体存在感**：兵力变少 → 每名武将必须有清晰定位、技能与养成价值；「拼出/合成出关键武将」的获得感远强于原版。
4. **保留品类爽点**：文字合成、拼字召唤、波次防守、羁绊构筑、军衔成长全部保留——这是原版成功的核心，不因差异化而动摇。
5. **竞技结构升级**：把原版 1V1 对称竞技异步化（机器人模拟真人、比坚持时长），在保留竞技感的同时降低实时匹配成本、适配小游戏碎片化场景。

### 3.2 差异化定位

**「武将列传式异步竞技塔防」**——玩家扮演长坂坡战场上的军师：征兵→拼字召唤名将→布阵防守→与（机器人模拟的）真人对手比谁守得更久。每个武将都是有名有姓的三国英雄，构成「拼字收集 + 构筑 + 防守 + 竞技」四位一体的体验。

### 3.3 核心玩法如何成立：武将继承兵种职能

原版兵种职能 → 我方武将职业映射（**职业 = 武将的兵种位**）：

| 原版兵种 | 战术职能 | 我方职业（示例武将） | 继承机制 |
| --- | --- | --- | --- |
| 枪 | 近战突进、贯穿清群 | 枪将·先锋（赵云） | 直线突进/贯穿伤害，克骑 |
| 刀/盾 | 近战抗线、群伤 | 刀将·战狂（张飞） | 近战 AOE/嘲讽，克枪 |
| 弓 | 远程持续输出 | 弓将·神射（周瑜） | 远程平 A + 全屏大招，压制近战 |
| 骑 | 机动冲锋、切后排 | 骑将·突袭（关羽/吕布） | 高移速冲锋、优先攻击后排，克刀 |

- **克制环**：枪 > 骑 > 刀 > 枪，弓 远程压制近战、被近身压制 → 保留原版兵种博弈，但博弈对象是「武将」，克制关系体现在职业标签上。
- **武将位即兵种位**：棋盘格上每个单位都是武将，站位分工（前排抗伤/中排输出/后排远程）依然成立。
- **合成升级为武将成长**：原版「兵种合成升级」改为「拼字召唤武将 + 同名武将三合一升星」。

### 3.4 与原版的体验差异

| 维度 | 原版《赵云与阿斗》 | 我方《阿斗与赵云》（武将版） |
| --- | --- | --- |
| 战场单位 | 兵种海（刀弓骑枪大量单位）+ 少量武将 | 纯武将小队（场上 ≤8 名，受人口约束），每名单位有名字 |
| 合成对象 | 兵种字牌二合一 + 拼姓名召唤武将 | **纯拼字召唤武将**（姓名 2–3 字牌集齐召唤）+ 三合一升星 |
| 竞技模式 | 1V1 实时对称（上下半场） | **1V1 异步**：机器人模拟真人，比坚持波数/时长 |
| 策略重心 | 兵种搭配 + 布阵 + 技能 | **武将构筑（职业/羁绊/技能搭配）** + 布阵 + 拼字优先级 |
| 单局手感 | 割草、铺场、合成上头 | 更聚焦：武将更耐打、技能更关键、站位更讲究 |
| 收集维度 | 武将 + 兵种 + 武器 | 武将（10 名精选）+ 武器/宝物（数量收敛、品质做深） |
| 题材一致性 | 兵种是工具人 | 每个单位都是历史名将，「救阿斗」叙事更强 |
| 美术成本 | 兵种与武将两套表现 | 只需武将表现（水墨字风 + 立绘），成本更低 |
| 上手门槛 | 中（兵种多、规则杂） | 低（单位少、每个武将一眼看懂） |

### 3.5 差异化风险与对策

| 风险 | 对策 |
| --- | --- |
| 单位少 → 场面不够「爽」、割草感弱 | 数值放大武将 AOE 范围与清场效率；保留「全屏大招」「连锁击杀」表现；波次密度照旧 |
| 无兵种字牌 → 拼字乐趣衰减 | 用「姓名拼字」替代「兵种合成」：字牌分稀有度、拼出 SSR 武将的高光时刻；同一武将多次拼出=升星，重复拼字仍有收益 |
| 克制环简化 → 深度不足 | 职业克制 + 技能克制 + 站位克制三层叠加 |
| 异步对战 → 缺乏实时竞技刺激 | 用「对手战绩快照 + 挑战前展示差距 + 实时进度对比条」营造对抗感；战胜后炫耀分享 |
| 与「没有普通单位」的直觉冲突 | 世界观解释：长坂坡只有赵云孤军救主，武将即是精锐；教学关直接演示「拼出赵云一人成军」 |

## 4. 我们版本的核心玩法设计

### 4.1 一句话玩法与目标玩家

> **征兵、拼字召唤名将、排兵布阵守住阿斗，与机器人模拟的真人对手比谁坚持得更久的异步竞技塔防小游戏。**

目标玩家：抖音/微信小游戏主力用户（休闲、碎片时间、零氪为主），单局 5–10 分钟，单手可玩。

### 4.2 核心模式：异步对战（评审反馈 1）

#### 4.2.1 模式定义

- **对战形式**：1V1 异步对战。玩家与「对手」各自独立进行一场标准防守局（波次配置完全相同），**比谁坚持得更久**（存活波数，通关后比用时与剩余阿斗血量）。
- **对手构成**：**机器人模拟真人**。
  - 优先取**真人战绩快照**：服务端保存真实玩家的最近防守战绩（存活波数、用时、阵容、军衔、昵称、头像），作为挑战目标；
  - 快照不足时（新服/低活跃时段）由**拟真人机器人**填充：按军衔分层生成战绩（机器人强度符合其「段位人设」，如军士级机器人约坚持 6–8 波、皇帝级约 24–28 波，叠加正态扰动模拟真人发挥波动），并配真人风格昵称/头像。
- **胜负判定**：玩家存活波数 > 对手 → 胜；= → 平（比用时/剩余血量）；< → 负。
- **公平性**：双方面对**完全相同的波次序列**（同一「对局种子」生成），仅玩家操作决定结果；玩家可查看对手的「防守阵容快照」作参考与学习。

#### 4.2.2 为什么这样设计

| 原版 1V1 实时竞技的问题 | 异步化后的收益 |
| --- | --- |
| 实时匹配依赖在线人数、等待长 | 无实时匹配，随时开战，碎片化友好 |
| 服务器成本高（同步战斗） | 只有「战绩快照」存储，成本极低 |
| 新手被高段位碾压、挫败 | 对手按军衔分层，永远有「差一点就赢」的目标 |
| 弱网/挂机体验差 | 纯本地防守局，无网络抖动影响 |
| 小游戏用户留存弱 | 「下次一定要超过他」的目标驱动再玩一局，天然留存钩子 |

#### 4.2.3 对战流程

```
主界面「征战」→ 系统分配对手（真人快照 / 拟真人机器人）
   ↓
挑战前展示：对手昵称/头像/军衔/战绩（如「坚持 15 波 · 9 分 20 秒 · 阵容快照」）
   ↓
玩家进入标准防守局（与对手同种子波次）
   ↓
防守至阿斗被破 / 通关上限（30 波）
   ↓
结算对比：我的坚持 vs 对手的坚持（进度对比条）
   ↓
胜：军衔积分 + 蜜罐币 + 炫耀分享；负：少量积分，鼓励再战
```

### 4.3 胜利条件与失败条件

- **单局目标**：在标准波次中**坚持到阿斗被破为止**（或通关 30 波上限）。坚持得越久，结算评价越高。
- **失败条件**：阿斗生命归零 / 敌军抵达营帐（阿斗所在格）。
- **对战判定**：与对手比「存活波数、用时、剩余血量」（§4.2.1）。
- **评价**：按「存活波数 + 击杀数 + 剩余血量」给 1–3 星，星级计入军衔积分（§5.1）。

### 4.4 局内循环（详细）

```
【准备】选技能（2 选 1：如「农民·经济」「招贤令·拼字」「陨石·攻击」，开局 1 个，中期可补）
   ↓
【征兵】消耗「馒头」征兵 → 随机获得武将姓名字牌（赵/云/关/羽…，按稀有度加权）或武将碎片
   ↓
【拼字召唤】集齐姓名全部字牌 → 拼字召唤武将上阵（如 赵+云=赵云）；重复拼出=升星
   ↓
【布阵】武将拖入棋盘格（受人口上限约束，前排/中排/后排）
   ↓
【作战】波次推进：武将自动攻击；玩家拖拽释放主动技能 / 三合一升星 / 拼字召唤
   ↓
【成长】每 3 波三选一 Roguelike 强化：技能强化 / 属性强化 / 免费拼字机会 / 馒头
   ↓
【终结】阿斗被破（失败）或通关 30 波 → 结算星级 → 与对手战绩对比 → 军衔积分
```

## 5. 系统与数值方向

### 5.1 成长线

1. **单局成长线**（5–10 分钟）：馒头经济 → 拼字召唤 → 升星 → 三选一强化 → 成型阵容。目标：每局有 2–3 个决策高光点（拼不拼、留不留怒、选哪个强化）。
2. **局外养成线**（天/周）：武将等级、星级、武器宝物、10 人收集率。目标：每周有明确成长；兑换码/活动做拉回流。
3. **段位成长线**（赛季）：军衔 11 级四梯队（沿用原版），异步对战胜场结算 → 军衔积分 → 晋升。目标：长期目标 + 对手分层的依据。

### 5.2 经济设计

| 货币 | 用途 | 产出 | 消耗 |
| --- | --- | --- | --- |
| 馒头（局内） | 征兵/拼字/强化 | 击杀、波次奖励、孙权被动、农民技能 | 征兵、拼字召唤、临时强化 |
| 字牌/碎片（局内） | 拼字召唤/升星 | 征兵随机获得 | 拼字、升星 |
| 蜜罐币（局外） | 养成主货币 | 对战结算、活动、广告（双倍）、IAP | 武将升级/碎片、武器强化 |
| 元宝/玉（付费货币） | 高端消费 | IAP | SSR 武将、稀有宝物、礼包 |
| 体力 | 局数限制 | 时间恢复、广告、IAP | 每局 1 点 |

- **免费玩家**：完整体验全部单局玩法、异步对战与军衔成长（对齐原版「零氪也能玩」）；付费点收敛在「加速养成 + 稀有武将」。
- **广告点位**（IAA）：体力 +1、结算双倍蜜罐币、战败「再试一次」（复活/重开）、免费征兵 1 次/日。
- **IAP 点位**：月卡（体力+每日礼包）、限时武将礼包、资源礼包。

### 5.3 关卡/对战结构

| 模式 | 结构 | 定位 |
| --- | --- | --- |
| **异步对战（核心）** | 挑战对手（真人快照/机器人）→ 标准防守局（同种子波次）→ 比坚持波数/时长 | **P0 核心模式**，军衔积分主来源 |
| 教学/新手关卡 | 3 关引导关：拼出赵云 → 布阵 → 守 5 波 | P0，解锁异步对战前置 |
| 主线章节（可选） | 章节制 PVE：长坂坡 → 当阳 → 汉水…，每章 5 关 | P1，解锁武将/皮肤/剧情 |
| 无尽模式 | 无限波次，按存活波数结算 | P1，长尾内容 + 蜜罐币来源 |
| 每日挑战 | 固定种子规则局（如「只用 3 名武将」） | P1，日活跃 + 活动载体 |

### 5.4 数值方向（初版框架，待配平）

**战斗公式（初版）**
- 最终伤害 = 攻击 × 技能系数 × (1 + 增伤 − 减伤) × 克制系数 × 暴击(1.5 倍)
- 克制系数：职业克制 1.25 / 被克 0.8 / 无克制 1.0
- 命中/闪避暂不做（手感和包体优先），用「格挡减伤」替代部分随机性

**难度曲线（初版建议）**
- 波次怪物血量成长：`怪物HP(n) = 基础HP × 1.08^(n-1)`，攻击成长 1.05 倍/波
- 精英波（5/10/15/20/25）：怪物量 ×1.5、血量 ×2；BOSS 波（10/20/30）：血量 ×8–10、带 1 个机制
- 单局目标时长 5–10 分钟；前 3 波为「经济爬坡期」（馒头收入 > 需求），4 波后难度抬头，玩家需在 6 波前完成第一次拼字召唤
- **机器人战绩分布**（拟真人机器人按军衔分层，供 §4.2 使用）：
  - 军士/校尉：坚持 5–9 波（均值 7，σ=1.5）
  - 少将/中将/上将：坚持 9–16 波（均值 12，σ=2）
  - 大将/元帅/诸侯：坚持 16–23 波（均值 19，σ=2.5）
  - 霸主/君主/皇帝：坚持 23–29 波（均值 26，σ=2）
  - 机器人「手感」模拟真人：约 8% 概率出现明显失误（晚拼字/漏放技能），约 5% 概率超常发挥

**单局经济（初版建议）**
- 馒头：击杀基础 8 馒头/单位，波次奖励 80+15n；首 3 波总收入 ≈ 可供 4 次征兵 + 1 次拼字
- 字牌：平均每次征兵 1 张字牌 + 概率碎片；SSR 字牌掉率 3%（SSR 武将 2–3 字 → 期望约 8–12 次征兵拼出首个 SSR）
- 目标曲线：**玩家应在 10–12 波达到「阵容成型」，15–18 波感受压力，20 波后每波都是生死线**——与机器人战绩分布对齐（皇帝级 26 波 ≈ 顶级玩家的现实上限）

**关键数值表骨架**（完整表由数值策划定稿后展开）：

| 表名 | 关键字段 |
| --- | --- |
| 武将表 | id、名称、职业、品质、人口占用、基础攻击/血量/攻速/移速、技能 id、羁绊 id |
| 技能表 | 技能类型（突进/眩晕/AOE/治疗/召唤/经济）、系数、冷却、怒气需求、成长 |
| 字牌表 | 字、所属武将、稀有度权重、拼字配方（姓名） |

| 羁绊表 | 成员、激活人数、效果、数值 |
| 经济表 | 击杀馒头、波次奖励、征兵概率、拼字消耗、升级费用曲线 |
| 军衔表 | 11 级、各级积分门槛、机器人战绩分布参数 |

### 5.5 运营与商业化要点（对齐原版打法）

- 上线买量单压抖音，素材主打「拼字召唤名将 + 零氪爽玩 + 长坂坡救阿斗 + 超过对手」；
- 兑换码/每日活动为常态化拉回流手段（原版验证有效）；
- 军衔排行榜提供社交攀比与分享点；异步对战的「战胜截图」天然适合分享裂变。

## 6. 技术实现建议概要

### 6.1 目标平台

| 优先级 | 平台 | 理由 |

### 6.3 关键技术点

- **异步对战服务端**：
  - 战绩快照存储（存活波数、用时、阵容、军衔、昵称/头像、对局种子）；无实时同步，服务端压力极低；
  - 拟真人机器人生成器：按军衔分层生成战绩（§5.4 参数），昵称/头像池避免撞脸；
  - 防作弊：对局种子 + 波次确定性由服务端下发，结算战绩服务端校验（本地篡改无效）。
- **存档**：局外进度本地存储 + 云存档（可选）；排行榜走抖音/微信开放数据域；
- **性能**：单位数少（武将 ≤6 人口 + 敌波 ≤40 单位），中端机 60fps；文字渲染用位图字体保证跨端一致；
- **热更**：小游戏分包 + 版本更新走平台审核；数值表远端下发（便于调价与运营）；
- **广告/支付**：接入抖音/微信平台 IAA（激励视频）与 IAP 能力。

## 7. 设计目标与验收标准

### 7.1 设计目标（体验/商业）

| 类别 | 目标 |
| --- | --- |
| 体验 | 单局 5–10 分钟；首局 60 秒内完成第一次拼字（拼出「赵云」）并理解「守阿斗」；核心循环「征兵→拼字→布阵→防守→对比对手」无断层 |
| 竞技 | 异步对战随时可开、无需等待；对手战绩按军衔分层，玩家始终有「差一点就赢」的目标 |
| 深度 | 10 名武将 / 6 羁绊 / 6 职业形成可构筑空间；每局至少 2 个决策高光点 |
| 商业 | 零氪可完整体验核心玩法；IAA+IAP 双通道；对齐「文字合成塔防 + 三国 + 水墨风」赛道 |
| 性能 | 中端机（骁龙 7 系档）60fps，包体 ≤ 40MB（首包） |

### 7.2 验收标准（方案定稿后开发必须实现 —— P0）

1. **异步对战闭环**：挑战对手（真人快照/机器人）→ 标准防守局 → 与对手比坚持波数/时长的胜负判定 → 军衔积分结算，全链路可玩；
2. **拟真人机器人**：按军衔分层生成战绩与表现（§5.4 参数），配真人风格昵称/头像，胜负感真实；
3. **字谜玩法**：征兵出字牌 → 拼凑姓名召唤武将（如 赵+云=赵云）→ 重复拼出升星，全流程生效；
4. **胜负判定**：阿斗被破即失败；坚持波数/用时/剩余血量的对比判定生效；
5. **武将体系**：**10 名武将（诸葛亮/曹操/关羽/赵云/吕布/刘备/张飞/周瑜/司马懿/孙权）、6 职业、6 羁绊**全部落地；职业克制（枪>骑>刀>枪、弓反制）数值生效；
6. **局内成长**：馒头经济、拼字召唤、三合一升星、三选一 Roguelike 强化（每 3 波一次）生效；
7. **局外养成**：武将等级/星级、武器宝物槽、蜜罐币经济闭环；
8. **军衔系统**：11 级军衔与积分规则生效，并作为机器人分层依据；
9. **体力与变现**：体力限制、广告点位（体力/双倍/再试一次/免费征兵）、至少 1 个 IAP 点位接入平台；
10. **平台达标**：抖音小游戏可运行，性能达标（§7.1）；
11. **新手引导**：教学关 3 关完成「拼字、布阵、放技能、守阿斗」四项教学，不打断节奏。

### 7.3 后续版本方向（P1/P2，不在本次验收范围）

- P1：主线章节 PVE、无尽模式、每日挑战、武将皮肤/改名、赛季军衔重置与赛季奖励；
- P2：真人实时对战（异步验证成熟后）、新武将扩充（第 11–20 名，如黄忠/马超/貂蝉/孙权系）、公会/好友互助（借武将守家）。
