## 1. 项目背景与设计目标

### 1.1 背景

本项目目标为复刻当前最热门的小游戏之一《赵云与阿斗》（用户侧称《阿斗与赵云》，见 §2.1 说明）。该游戏 2026 年 6 月上线抖音小游戏后快速登顶抖音小游戏双榜第一（DataEye Adx 买量数据、北京商报报道），是当下最具代表性的休闲塔防爆款，验证了「文字合成塔防 + 三国题材 + 零氪也能玩」这一组合的市场潜力。

### 1.2 差异化约束（硬性要求）

> **与目前游戏的区别：我们做的只有武将，没有「骑」「弓」这种普通单位。**

即：原版中「刀、弓、骑、枪」四类可合成的普通兵种，在本项目中**整体移除**。场上存在的战斗单位只有**武将**（含其召唤物/技能衍生单位，但不再有「可批量招募的普通兵种」）。

### 1.3 设计目标（总览）

1. **保爽点**：保留原版「合成上头 + 波次割草 + 养成正反馈」的核心体验；
2. **做差异**：以「武将即单位」重构战斗深度，突出每名武将的存在感与技能博弈；
3. **控成本**：文字风美术、小体量、单指操作，适配抖音/微信小游戏生态与 IAA/IAP 混合变现；
4. **可落地**：输出可直接转开发的系统结构、数值方向与验收标准。

## 2. 原游戏《赵云与阿斗》玩法拆解

> 说明：本拆解基于公开资料（媒体报道、攻略站点、TapTap 论坛、B 站演示视频），确定性标注见 §2.6。当前没有可试玩的官方版本，**具体数值与部分机制存在不确定性**，下文以「确定性：高/中/低」标注。

### 2.1 市场表现与产品定位（确定性：高）

| 维度 | 事实 |
| --- | --- |
| 上线时间/平台 | 2026 年 6 月初上线**抖音小游戏**，买量单压抖音（DataEye Adx） |
| 市场成绩 | 上线约一个月位居**抖音小游戏双榜第一**（畅销榜登顶；媒体标题「不氪金的小游戏靠什么登顶畅销榜」） |
| 类型 | 文字合成塔防（融合合成、塔防、Roguelike、羁绊养成） |
| 题材包装 | 三国·长坂坡救主：**保卫瑟瑟发抖的阿斗** |
| 美术风格 | 文字风（兵种/单位以汉字呈现，如拖动「刀」「弓」合成） |
| 变现模式 | 零氪可玩 + 畅销榜登顶 → IAP 内购为主、IAA 广告为辅的混合变现 |

**名称说明**：公开资料中游戏官方名称为**《赵云与阿斗》**（TapTap、北京商报、GameLook、B 站均以此名收录）；用户侧称《阿斗与赵云》，判定为同一款游戏（名称顺序差异），本方案统一称原版为《赵云与阿斗》，我方项目名沿用《阿斗与赵云》。

### 2.2 核心玩法循环（确定性：中-高）

```
布阵（摆放武将/兵种到棋盘格子）
   ↓
开战（波次敌军从固定路径进犯，目标突破防线）
   ↓
局内成长（杀敌得金币 → 合成升级兵种/武将 → 三选一强化）
   ↓
高压波 / BOSS 关（13 波后多轮 BOSS + 精英怪潮）
   ↓
结算（按存活波数/表现给星级 → 军衔积分）
   ↓
局外成长（升级武将、解锁新武将、军衔晋升）
   ↻ 下一局
```

关键节奏（确定性：中）：开局 1–5 波发育攒资源、铺满棋盘；中期 6–12 波成阵型（桃园羁绊等）；后期高压波 + BOSS，守不住则防线被突破、失败。

### 2.3 主要系统拆解

#### 2.3.1 合成系统（确定性：中-高）
- 核心操作：**拖动「刀」「弓」等兵种汉字合成士兵**（B 站演示：「拖动 刀 弓 合成士兵，召唤赵云救主」）。
- 合成货币：攻略中出现「包子」「馒头」等称呼（低阶单位合成高阶/召唤武将的消耗品）。
- 体验特征：合成反馈即时、上头，属于「合成放置/合成塔防」品类的标准心智。

#### 2.3.2 塔防布阵系统（确定性：中）
- 棋盘/格子制布阵，攻略反复强调「铺满棋盘空位，杜绝敌军偷袭漏洞」。
- 站位分工明确：前排肉盾（张飞等）、中路核心输出（赵云，贯穿伤害双线清怪）、后排远程补伤。
- 有「堵门流」等社区打法（TapTap 帖子），说明敌方单位有固定出兵口/路径，存在卡位博弈。

#### 2.3.3 兵种系统（确定性：高）
- 原版存在 **刀、弓、骑、枪** 四类普通兵种（TapTap 帖子「弓骑枪刀四兵种摆放优先级」；B 站演示「拖动 刀 弓 合成士兵」）。
- 兵种承担职能分工：枪（近战突进）、弓（远程）、刀（近战群伤）、骑（机动/冲锋）。

#### 2.3.4 武将系统（确定性：高，来自 CSDN 攻略）
武将即英雄单位，携带唯一技能，与兵种配合上场。已知名单与技能：

| 武将 | 定位 | 技能 | 备注 |
| --- | --- | --- | --- |
| 赵云 | 枪系核心 | 「七进七出」：直线突进群伤 | 输出+坦度，前排首选，必选主将 |
| 阿斗 | 辅助核心 | 无输出，提供全队续航与羁绊增益 | 必须保护（被突破即败局） |
| 张飞 | 近战爆发 | 「大喝」：眩晕周围敌人 | 清杂兵高效 |
| 黄忠 | 远程弓手 | 全屏箭矢：持续伤害+击退 | 清场利器 |
| 关羽 | 单体高伤 | 突进收割，克制精英与 BOSS | 收割型 |
| 刘备 | 范围控场 | 小幅增伤，缓解防线压力 | 桃园羁绊核心 |
| 魏延 | 纯肉前排 | 高减伤、吸引仇恨 | 保护后排 |

#### 2.3.5 羁绊系统（确定性：中-高）
- 已有明确实例：**桃园羁绊**（刘关张）→ 灼烧伤害翻倍（确定性：中，攻略称「激活桃园羁绊，灼烧伤害翻倍」）。
- 羁绊是阵容深度的主要来源，驱动「凑羁绊」的构筑乐趣。

#### 2.3.6 武器/道具系统（确定性：中）
- 武将可携带武器/符/丹药，如赵云：点钢枪（击杀叠攻速）、龙吟亮胆枪（飞枪额外伤害）、攻速符、神兵符（金色增伤）、防御配饰。
- 阿斗适配道具：大补丸、续命丹（提升全队生命与容错）、行军丹（保留体力，应对怪潮）。
- 说明存在「体力」资源（局内或局外），且道具影响数值上限。

#### 2.3.7 军衔/段位系统（确定性：中-高）
- **11 级军衔**：军士 → 校尉 → 少将 → 中将 → 上将 → 大将 → 元帅 → 诸侯 → 霸主 → 君主 → 皇帝。
- 分四梯队：新手（军士/校尉）、进阶（少将/中将/上将）、高阶（大将/元帅/诸侯）、顶尖（霸主/君主/皇帝）。
- 晋升依据：**对局积累星级**（通关评价 → 星级 → 军衔积分）。

#### 2.3.8 货币与运营（确定性：中）
- 局内货币：金币/馒头类合成资源；局外货币：「蜜罐币」（B 站兑换码活动赠送 88888 蜜罐币）。
- 运营手段：兑换码、每日活动、0 点技能重置（TapTap 帖子「0 点技能不重置小技巧」——说明技能有每日重置/每日收益机制）。
- 体力限制存在（「无限体力版」流行佐证），是广告/付费消耗点。

### 2.4 商业化模式（确定性：中）
- IAP：畅销榜登顶说明内购（武将/道具/资源礼包）为主要收入。
- IAA：体力恢复、复活、双倍结算等广告点位（「免广告版」流行佐证广告存在）。
- 买量：单压抖音，素材主打「零氪爽玩、文字合成上头」。

## 3. 差异化设计：只有武将的世界

### 3.1 设计原则

1. **删繁就简，武将即一切**：移除普通兵种后，战场上的「单位」100% 是武将。合成对象、招募对象、站位对象全部收敛到武将。
2. **职能不丢失**：原版四兵种（刀/弓/骑/枪）的战术职能，由**武将职业体系**继承（见 §3.3 映射），保证战术深度不因删兵种而坍塌。
3. **放大单体存在感**：兵力变少 → 每名武将必须有清晰的定位、技能与养成价值，「抽到/合成出关键武将」的获得感要远强于原版。
4. **保留品类爽点**：合成上头、波次割草、羁绊构筑、军衔成长全部保留，这是原版成功的核心，不因差异化而动摇。

### 3.2 差异化定位

**「武将列传式轻塔防」**——玩家扮演长坂坡战场上的军师，用「合成武将、布阵、放技能」守护阿斗。每个武将都是有名有姓的三国英雄，有独立技能与故事梗，构成「收集 + 构筑 + 防守」三位一体的体验。

### 3.3 核心玩法如何成立：武将继承兵种职能

原版兵种职能 → 我方武将职业映射（**职业 = 武将的兵种位**）：

| 原版兵种 | 战术职能 | 我方职业（示例武将） | 继承机制 |
| --- | --- | --- | --- |
| 枪 | 近战突进、贯穿清群 | 枪将·先锋（赵云） | 直线突进/贯穿伤害，克骑 |
| 刀 | 近战群伤、站桩输出 | 刀将·战狂（张飞/魏延） | 近战 AOE，克枪 |
| 弓 | 远程持续输出 | 弓将·神射（黄忠） | 远程平 A + 全屏大招，克制近战 |
| 骑 | 机动冲锋、切后排 | 骑将·突袭（马超/关羽） | 高移速冲锋、优先攻击后排，克刀 |

- **克制环**：枪 > 骑 > 刀 > 枪，弓 远程压制近战、被近身压制 → 保留原版兵种博弈，但博弈对象是「武将」，克制关系体现在武将职业标签上。
- **武将位即兵种位**：棋盘格上放的每个单位都是武将，站位分工（前排抗伤/中路输出/后排远程）依然成立。
- **合成升级为武将成长**：原版「兵种合成升级」改为「同名/同职武将三合一升星」+「低阶武将合成召唤高阶武将」。

### 3.4 与原版的体验差异

| 维度 | 原版《赵云与阿斗》 | 我方《阿斗与赵云》（武将版） |
| --- | --- | --- |
| 战场单位 | 兵种海（刀弓骑枪大量单位）+ 少量武将 | 纯武将小队（场上 6–10 名），每名单位有名字 |
| 合成对象 | 兵种汉字拖拽合成、积攒货币召唤武将 | 武将碎片/令牌合成、三合一升星、召唤新武将 |
| 策略重心 | 兵种搭配 + 布阵 + 武将技能 | **武将构筑（职业/羁绊/技能搭配）** + 布阵 + 技能释放时机 |
| 单局手感 | 割草、铺场、合成上头 | 更聚焦：武将更耐打、技能更关键、站位更讲究 |
| 收集维度 | 武将 + 兵种 + 武器 | 武将 + 武器/宝物（数量收敛、品质做深） |
| 题材一致性 | 兵种是工具人 | 每个单位都是历史名将，「救阿斗」叙事更强 |
| 美术成本 | 需兵种与武将两套表现 | 只需武将表现（文字风 + 立绘），成本更低 |
| 上手门槛 | 中（兵种多、规则杂） | 低（单位少、每个武将一眼看懂） |

### 3.5 差异化风险与对策

| 风险 | 对策 |
| --- | --- |
| 单位少 → 场面不够「爽」、割草感弱 | 数值上放大武将 AOE 范围与清场效率；保留「全屏大招」「连锁击杀」等表现；波次密度照旧 |
| 合成对象单一 → 合成乐趣衰减 | 引入「武将三合一升星 + 同职合体技 + 羁绊激活」，合成反馈频率不低于原版 |
| 克制环简化 → 深度不足 | 用职业克制 + 技能克制 + 站位克制三层叠加补深度 |
| 与「没有普通单位」的直觉冲突（玩家问「兵呢？」） | 用世界观解释：长坂坡只有赵云孤军救主，武将即是精锐；教学关直接演示「武将一人成军」 |

## 4. 我们版本的核心玩法设计

### 4.1 一句话玩法与目标玩家

> **合成武将、排兵布阵，守住阿斗，在波次进攻中打出名将连招的轻塔防小游戏。**

目标玩家：抖音/微信小游戏主力用户（休闲、碎片时间、零氪为主），单局 8–15 分钟，单手可玩。

### 4.2 胜利条件与失败条件

- **胜利**：撑过本关全部波次（含最终 BOSS 波），阿斗存活。
- **失败**：防线被突破 —— 敌军到达棋盘末端「营帐」（阿斗所在格）或阿斗生命归零；阿斗被击杀/掳走即失败（贴合「救阿斗」主题）。
- **评价**：结算按「存活波次、剩余阿斗血量、击杀数、用时」给 1–3 星，星级计入军衔积分（§5.1）。

### 4.3 局内循环（详细）

```
【准备阶段】布阵：把上阵武将放入棋盘格（前排/中排/后排），确认羁绊
   ↓
【作战阶段】波次推进：
   ① 敌军从固定出兵口成波进犯（步骑弓混合、5 波一精英、10 波一 BOSS）
   ② 武将自动攻击，玩家操作：拖拽释放武将主动技能 / 三合一升星 / 放置新武将
   ③ 杀敌掉金币与武将令牌；阿斗每波回少量血并提供全局增益
   ↓
【成长阶段】波次间隙（或每 3 波）三选一 Roguelike 强化：
   选项 = 技能强化 / 属性强化 / 直接召唤随机武将 / 金币
   ↓
【Boss 阶段】每关 10 波与 20 波出 BOSS（如曹仁、许褚、张郃…），BOSS 有技能条
   ↓
【结算】星级 → 军衔积分 → 局外货币（蜜罐币）→ 解锁/养成
```

单关规模：**20 波 = 3 精英 + 2 BOSS**（对标原版「13 波后多轮 BOSS」的节奏，平滑后 20 波定标）。

### 4.4 武将能力体系

#### 4.4.1 职业（定位）体系

| 职业 | 兵种标签 | 定位 | 攻击方式 | 克制 | 被克制 |
| --- | --- | --- | --- | --- | --- |
| 枪将（先锋） | 枪 | 突进群伤、半坦 | 直线贯穿突进 | 骑 | 刀 |
| 刀将（战狂） | 刀 | 站桩群伤、纯输出 | 近战横扫 | 枪 | 骑 |
| 骑将（突袭） | 骑 | 机动切后、收割 | 冲锋突袭 | 刀 | 枪 |

#### 4.4.3 武将品质与合成路线

- **品质**：N（小兵级武将，如廖化、周仓）→ R（如关平、马岱）→ SR（如马超、魏延）→ SSR（如赵云、关羽、诸葛亮）。
- **合成规则**：
  - **三合一升星**：场上任意 3 个同名武将可合成升星（1 星→2 星→3 星），升星提升属性与技能等级；
  - **召唤合成**：消耗「令牌」（局内掉落）可召唤随机武将；同职 3 个不同武将可「合体召唤」该职业更高一级随机武将（继承部分强化，对标原版「合成士兵」的即时反馈）；
  - **羁绊激活**：满足条件（如刘关张同场）自动激活，无需额外操作。
- **局外解锁**：新武将通过关卡解锁/蜜罐币抽取/活动获取，重复获取转化为碎片（升星素材）。

## 5. 系统与数值方向

### 5.1 成长线

三条并行成长线，分别承接局内、局外与长期目标：

1. **单局成长线**（10–20 分钟）：金币升级 → 武将升星 → 三选一强化 → 成型阵容。目标：每局有 2–3 个「决策高光点」（何时合、留不留怒、选哪个强化）。
2. **局外养成线**（天/周）：武将等级、星级、武器宝物、武将收集率。目标：每周有明确成长；兑换码/活动做拉回流。
3. **段位成长线**（赛季）：军衔 11 级四梯队（沿用原版），星级结算 → 军衔积分 → 晋升。目标：提供长期目标与炫耀点，支撑排行榜。

### 5.2 经济设计

| 货币 | 用途 | 产出 | 消耗 |
| --- | --- | --- | --- |
| 金币（局内） | 局内升级 | 击杀、波次奖励 | 武将升级、临时强化 |
| 令牌（局内） | 合成/召唤 | 击杀掉落、波次奖励、三选一 | 合成、召唤 |
| 蜜罐币（局外） | 养成主货币 | 通关结算、活动、广告（双倍）、IAP | 武将升级/碎片、武器强化 |
| 元宝/玉（付费货币） | 高端消费 | IAP | SSR 武将、稀有宝物、礼包 |
| 体力 | 局数限制 | 时间恢复、广告、IAP | 每局 1 点 |

- **免费玩家**：可完整体验全部单局玩法与军衔成长（对标原版「不氪金登顶畅销榜」——畅销来自大量微氪），付费点收敛在「加速养成 + 稀有武将」。
- **广告点位**（IAA）：体力 +1、结算双倍蜜罐币、战败复活（每局 1 次）、免费召唤 1 次/日。
- **IAP 点位**：月卡（体力+每日礼包）、限时武将礼包、资源礼包。

### 5.3 关卡/对战结构

| 模式 | 结构 | 定位 |
| --- | --- | --- |
| 主线关卡（章节制） | 每章 5 关，每关 20 波（3 精英 + 2 BOSS）；章节名：长坂坡 → 当阳 → 汉水 → 赤壁 → 夷陵 … | 核心内容，解锁武将/武器/新章节 |
| 无尽模式 | 无限波次，难度递增，按存活波数结算 | 长尾内容 + 军衔积分主来源 |
| 每日挑战 | 固定种子阵容/规则（如「只用 3 武将」），限次参与 | 日活跃 + 兑换码/奖励活动载体 |
| 精英/BOSS 关 | 主线内嵌，BOSS 有技能条与机制（召唤/冲锋/回血） | 单局高潮点 |
| （远期）玩家对战 | 异步镜像防守战 | P2，见 §7.3 |

### 5.4 数值方向（初版框架，待配平）

**战斗公式（初版）**
- 最终伤害 = 攻击 × 技能系数 × (1 + 增伤 − 减伤) × 克制系数 × 暴击(1.5 倍)
- 克制系数：职业克制 1.25 / 被克 0.8 / 无克制 1.0
- 命中/闪避暂不做（小游戏手感和包体优先），用「格挡减伤」替代部分随机性

**难度曲线（初版建议）**
- 波次怪物血量成长：`怪物HP(n) = 基础HP × 1.08^(n-1)`，攻击成长 1.05 倍/波
- 精英波（5/10/15）：怪物量 ×1.5、血量 ×2；BOSS 波（10/20）：血量 ×8–10、带 1 个机制
- 单局 20 波目标时长 10–13 分钟；前 5 波为「经济爬坡期」（杀敌速度 > 需求），6 波后难度抬头，玩家需在 8 波前完成首次升星

**单局经济（初版建议）**
- 金币：击杀基础 10 金/单位，波次奖励 100+20n 金；首 5 波总收入 ≈ 可供 3 次武将升级 + 1 次召唤
- 令牌：平均每波掉落 2–3 枚，三合一升星需求 3 枚/次 → 玩家每 2 波可完成一次合成决策
- 目标曲线：**玩家应在 12–14 波达到「阵容成型」，15–18 波感受压力，20 波 BOSS 需要留怒 + 羁绊 + 升星全部到位才能过**——保证「差一点就赢」的再玩一局冲动

**关键数值表骨架**（完整表由数值策划在定稿后展开）：

| 表名 | 关键字段 |
| --- | --- |
| 武将表 | id、名称、职业、品质、基础攻击/血量/攻速/移速、技能 id、羁绊 id |
| 技能表 | 技能类型（突进/眩晕/AOE/治疗/召唤）、系数、冷却、怒气需求、成长 |
| 关卡表 | 章节、关卡、波次数、每波敌人构成、难度系数、星级条件 |
| 羁绊表 | 成员、激活人数、效果、数值 |
| 经济表 | 击杀金币、波次奖励、召唤概率、升级费用曲线 |
| 军衔表 | 11 级、各级积分门槛、奖励 |

### 5.5 运营与商业化要点（对齐原版打法）

- 上线买量单压抖音，素材主打「文字合成上头 + 零氪爽玩 + 长坂坡救阿斗」；
- 兑换码/每日活动为常态化拉回流手段（原版验证有效）；
- 排行榜（军衔）提供社交攀比与分享点。

- **防破解**：体力/货币关键逻辑服务端校验（小游戏反作弊弱，先防「本地篡改礼包」即可）。

## 7. 设计目标与验收标准

### 7.1 设计目标（体验/商业）

| 类别 | 目标 |
| --- | --- |
| 体验 | 单局 8–15 分钟；首局 60 秒内完成第一次合成并理解「守阿斗」；核心循环「合成→布阵→割草→BOSS→结算」无断层 |
| 深度 | 首批 12 武将 / 5 羁绊 / 6 职业形成可构筑空间；每局至少 2 个决策高光点 |
| 商业 | 零氪可完整体验主线；IAA+IAP 双通道；对齐「休闲塔防 + 三国 + 文字风」赛道 |
| 性能 | 中端机（骁龙 7 系档）60fps，包体 ≤ 40MB（首包） |

### 7.2 验收标准（方案定稿后开发必须实现 —— P0）

1. **单局闭环**：布阵 → 合成/召唤 → 20 波战斗（含精英与 BOSS）→ 星级结算 → 军衔积分，全链路可玩；
2. **胜负判定**：阿斗被突破即失败；撑过 20 波即胜利；星级条件生效；
3. **武将体系**：≥12 名武将、6 职业、5 羁绊全部落地，职业克制（枪>骑>刀>枪、弓反制）数值生效；
4. **合成系统**：三合一升星、令牌召唤、召唤物（黄月英机关弩）可用，合成反馈（表现/音效/飘字）达标；
5. **局内成长**：金币升级 + 三选一 Roguelike 强化（每 3 波一次）生效；
6. **局外养成**：武将等级/星级、武器宝物槽、蜜罐币经济闭环；
7. **军衔系统**：11 级军衔与积分规则生效；
8. **体力与变现**：体力限制、广告点位（复活/双倍/免费召唤）、至少 1 个 IAP 点位接入平台；
9. **平台达标**：抖音小游戏可运行，性能达标（§7.1）；
10. **新手引导**：前 3 波完成「合成、放置、放技能、守阿斗」四项教学，不打断节奏。

### 7.3 后续版本方向（P1/P2，不在本次验收范围）

- P1：无尽模式、每日挑战、武将皮肤/改名、赛季军衔重置与赛季奖励；
- P2：玩家对战（异步防守镜像）、新章节（东吴/曹魏武将池）、公会/好友互助（借武将守家）。
