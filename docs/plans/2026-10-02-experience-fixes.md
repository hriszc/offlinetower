# 游戏体验修复 Implementation Plan

**Goal:** 修复体验报告中的确定问题与动物选人显示异常，让策略收益、教学、结算和会话恢复可理解且可靠。

**Architecture:** 保留纯前端与当前存档键。数值修复使用已有属性；单人大局在既有存档中新增可选 run 断点，战斗中断恢复到该局备战；合作普通返回仅离开本机视图，解散为明确操作。选人布局按舞台逻辑宽高适配，避免竖屏旋转后使用错误的视口尺寸。

**Tech Stack:** 原生 JavaScript、CSS、Canvas、Node、Playwright Chrome。

## 1 数值与可见战斗统计

修改 js/config.js、js/sim.js、js/coop-sim.js；增加 tools/verify_gameplay.js。修尸学笔记倍率、两件空效果遗物、合作初始血量；结算取主战斗快照，并记录首个家园受击路用于失败提示。用 Node 验证组合倍率、家园与统计。

## 2 会话与教学

修改 js/meta.js、js/ui.js、js/main.js、index.html。教学引导熊20+豪猪30+浣熊45，错误落点不扣钱。加入暂停、返回菜单及小局备战/结算续玩；满血急修不扣次数、空照明弹可重新选择；回收提供撤销。旧存档无 run 时按原行为读取。

修改 js/coop.js。返回保留同一席位与房间；刷新不主动通知房主离开；连接页可返回/重试；解散明确全队影响并确认。用本地拦截 API 验证，不操作线上房间。

## 3 选人和小屏操作

修改 css/style.css、js/ui.js。去除选人固定行高、真实视口媒体查询与旋转舞台的冲突；卡片内容自然高度、确认栏常驻、列表独立滚动，保留数量与效果。卡片提供键盘选择，Canvas 提供网格焦点与点击替代；手机至少改善文字、单位信息和技能按钮，保留战场空间。

## 4 集中验收与产物

使用 develop-web-game 标准客户端与一趟自定义 Chrome 检查新手完整阵型、错误落点、升形态/回收撤销、暂停/续玩、结算、五种手机横竖屏选人滚动与卡片边界、合作返回/断网。运行 verify_gameplay、verify_coop、verify_monetize、verify_i18n，修正过时双语断言。所有截图放 output/playwright。执行 build_all 刷新三端网页资源，核验渠道允许的共同文件一致性；不部署线上服务或提交商店。

## 完成记录

选动物界面已改为舞台尺寸驱动的三/四列自然行高布局，卡片说明与锁定信息不溢出，底部数量和确认按钮固定可见，列表支持触屏滑动。原先所有已解锁动物都显示勾号的问题已改为仅勾选当前六只。重玩教学时自动带齐三只必需动物并锁定，避免自定义阵容无法完成教学。

单人增加暂停和备战/结算/奖励断点恢复。暂停时焦点留在浮层内，布防、升级、回收和开战写操作均被拦截。战斗中返回菜单或刷新后从本小局备战重新开始，存档键未变，旧存档没有断点时正常读取。满血急修与空照明弹不扣次数，回收后五秒可撤销；普通提示不拦截战场点击。

遗物倍率与初始血量修复同时应用到单人和合作，原遗物ID保留。结算读取实际结束时的击杀/时间/血量快照，显示家园血量对比、战斗时长和首个受击路线提示。合作普通返回菜单保留席位、草稿与心跳，解散需要明确确认，离线界面支持重试/返回。服务器既有15秒离线判定仍生效，长时间真正断线不会永久保留席位。

验证结果：体验75项、双语布局14组、合作模拟75项、客户端生命周期24项、变现26项通过；手机布局16档及合作左右侧/触屏检查通过。浏览器截图与状态位于 output/playwright/experience-fixes/。标准游戏测试客户端使用本机Chrome完成，点击等待提示超时但实际已进入选人，完整行为由上述集中回归覆盖。

node tools/build_all.js已重建iOS资源、H5和小工具包，15个核心文件逐字节一致。未部署线上Worker/静态站点或提交App Store；发布新版合作客户端时需要同步部署本地更新的合作模拟与配置，线上旧Worker不属于本次验证结果。
