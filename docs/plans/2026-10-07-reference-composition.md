# Reference Composition Implementation Plan

**Goal:** 将整体构图、插画氛围与主要操作区改成用户已确认六界面参考图的方向，修正小插画+大奶油面板和右侧商店造成的整体差距。

**Architecture:** 首页使用正式夜色绘本插画作满幅背景，文字与按钮保留真实DOM。伙伴/升级/奖励卡沿用现有数据和全部入口，调整大图、徽章与圆形阵容头像。战场改用底部横排六卡托盘，渲染和输入共用场地纵向视图映射，保留九路模拟坐标、单人和合作足迹。美术资产写入assets并登记唯一打包清单，三端同源。

**Tech Stack:** 原生HTML/CSS、Canvas 2D、内置imagegen、Playwright固定帧验证。

1. 用已批准参考图制作无字无按钮的夜色首页插画；保存prompt和成品，放入assets并登记tools/pack_manifest.js。
2. 首页满幅场景/奶油大标题/琥珀主操作/蓝色合作操作/底部辅助入口；状态与规则折叠区保持可访问。伙伴三列大卡、角色徽章、圆形六头像，升级和奖励突出图像、实际结果采用庆祝动物场景。
3. 底部商店六卡横排，独立开始防守按钮，手机矮屏保留名称价格与操作可达。九路场地纵向适配托盘预留空间；Render与UI共享view映射，点按/拖动/面板/教学/照明弹定位一致。
4. 战场调整深蓝林缘、草丛石路、暖屋灯光、小屋边栏、简化可放置格与柔橙裂口；缓存静态部分，保留战斗提示和所有规则。
5. 合并一次验证点按/拖动/教学/合作定位、矮屏双语布局、594动物边界、暂停/设置和完整战斗流程；查看实际六界面，打包检查三端资源一致，更新用户现有预览。
