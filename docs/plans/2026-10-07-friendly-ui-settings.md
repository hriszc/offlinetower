# 全年龄界面第二轮 Implementation Plan

**Goal:** 按用户“继续完善各界面，更贴近参考图”的选择，精修伙伴大卡片、首页、卡通小屋与通道、升级奖励和结算，同时补齐设置入口。

**Architecture:** 使用现有 DOM 浮层，首页与暂停都能进入设置。偏好继续存入 yeshou.save.v1，新增字段提供默认值；三端资源和玩法保持同源。音量仅调整现有 WebAudio 总增益，减少动效同时遵循系统设置。

**Tech Stack:** 原生 JavaScript/CSS、WebAudio、Canvas、现有 Playwright。

1. `js/render.js`：程序化小屋门廊暖灯、简洁石板草边、灰蓝锁定区域、柔和橙色裂隙，保持九路几何和模拟。
2. `js/meta.js`、`js/audio.js`、`js/main.js`：默认偏好、读取归一化、音量增益和减少闪光/震动。
3. `js/ui.js`、`js/config.js`：伙伴大图与简短文案布局，升级/奖励/结算图标层级；首页/暂停设置入口，原生checkbox/range，立即反馈、持久化、正确返回原浮层；双语文案。
4. `css/style.css`：三列伙伴卡与角色图文布局、清楚的主要操作、易读设置面板与大字模式，手机矮屏关键按钮可见，原生触控与键盘焦点；用户减少动效与系统偏好同时生效。
5. 一趟浏览器验证旧存档默认值、设置持久化、音量实时增益、暂停返回、减少闪光、大字在双语旋转/矮屏下的布阵和升级/结算布局。运行既有相关交互/门禁回归，刷新预览与三端包。
