# Animal Reference Art Implementation Plan

**Goal:** 修正动物形象与已确认参考图的差距，重画22种动物，使坐姿/站姿、点眼、脸型、尾巴与物种轮廓鲜明。

**Architecture:** 保留同一Canvas绘制入口`Render.drawAnimal`，所有首页、缩略图、战场与升级图自动复用。用独立曲线路径替代通用横向椭圆模板；不改物种、技能、等级、足迹、朝向与战斗模拟。动物在现有140设计像素离屏框内保留耳尾翅，沿用主体裁切与缓存。

**Tech Stack:** 原生Canvas 2D路径、现有离屏精灵/缩略图缓存、Playwright、三端同源打包。

1. 对照`output/imagegen/ui-all-ages-reference-v1.png`：熊坐姿/小圆耳/短前掌，狐狸尖脸/奶油胸/蓬松尾，兔子长耳/小前爪/红围巾，萤火虫深色头/点眼/黄色发光腹；其他现有动物各自保持可识别轮廓，鸟类参考鸽子的自然侧姿。
2. 局部替换`js/render.js`中动物绘制方法，统一深暖灰描边和柔和分区阴影；不增加夸张眼白，不使用一套身体拼所有动物。升级色彩小饰件与受击/攻击反馈保留。
3. 批量导出22种动物实际缩略图与旧/新对照，检查96px卡片和48px战场尺寸；运行198个主体边界检查，验证耳尾不裁、三等级/三密度完整。
4. 一次游戏客户端与实际六界面流程验证，检查控制/奖励/升级和JS错误；刷新六界面总览，执行`node tools/build_all.js`检查三端核心逐字节一致。
