# 合作战斗沿用单人战斗规则

## 目标

合作战斗直接运行 `js/sim.js` 的 `Battle` 核心，让建筑射程、跨路攻击、火焰与毒液喷幅、钉刺接触反伤、墙体阻挡、僵尸攻击与死亡效果沿用单人规则。合作层只负责把玩家布防映射到九路、按人数放大尸潮并分配到存活家园、分别统计家园生命值；某座家园失守后，该玩家建筑停止工作，僵尸改攻仍存活的家园。两到三名玩家仍使用独立金币、段位和遗物。

Worker 与客户端使用同一确定性战斗核心和种子：Worker 只保存结算结果，客户端按固定步长运行同一场战斗并用现有真实战场绘制，不上传战斗帧。当前“预先结算后按轨迹绘制”的合作抽象模拟退出。

合作 HUD 在触屏/窄屏设备默认折叠为小按钮，展开后显示队伍与离开操作；离开后清除本地房间凭证，以便立即新建或加入其他房间。桌面布局保留展开状态。

## 实现步骤

1. 让单人战斗核心在浏览器中保持原用法，同时以 CommonJS 导出供 Worker 调用；导出所需战斗配置并保持单人默认路径不变。
2. 增加合作战斗适配：九路布防、逐玩家遗物与家园、按人数放大出怪、倒下后停用该玩家建筑并重定向其僵尸、全队失守或限时结束。
3. Worker 与客户端改为调用同一合作战斗工厂；客户端固定步长运行真实 `Battle` 并更新九路家园 HUD。
4. 钉刺恢复为接触反伤语义，合作画面不再合成错误的远程攻击；折叠移动端 HUD，离房时清除 session。
5. 跑合作 API/战斗回归和三端构建，使用浏览器核对合作战场、队友支援、手机 HUD 与离房后重新建房入口。
