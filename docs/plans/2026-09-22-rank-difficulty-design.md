# 排位压力难度设计

## 目标

排位分不再只是段位展示。玩家分数越高，同一小局的尸潮和镜像对手越强，让高分段对构筑、操作和资源规划提出更高要求。

## 压力曲线

压力值在段位区间内连续插值，升段瞬间保持连续：

| 排位分 | 段位 | 压力 |
| --- | --- | --- |
| 0 | 拾荒者 | 100% |
| 350 | 木屋守夜人 | 104% |
| 800 | 铁闸守卫 | 109% |
| 1350 | 加固工头 | 114% |
| 2000 | 堡垒指挥官 | 120% |
| 2800+ | 永夜要塞 | 127% |

`rankPressure(score)` 是唯一入口；战斗、机器人和 HUD 都读取同一个值。

## 战斗影响

- 尸潮生命按压力全额提高。
- 丧尸伤害提高压力增量的 70%，速度提高 25%，避免高分段只变成数值拖延。
- 常规刷怪间隔缩短，脉冲间隔缩短、规模扩大。
- 奔逃者、肿汉和铁皮尸的权重小幅提高，强化高压局的处理要求。
- 玩家初始金币、收入、技能次数和建筑数值不因排位分削弱。

## 镜像影响

- 镜像预算额外增加压力增量的 18%。
- 镜像建筑生命与伤害额外乘压力增量的 80%。
- 镜像战力评分同步提高，便于玩家在备战期识别高压局。

## 反馈与兼容

- HUD 在排位压力高于 100% 时显示“排位压力 +x%”。
- `roundWave`、`makeBot` 和 `Battle` 的压力参数均可省略，默认保持原难度，兼容旧测试与调用。
- 平衡工具新增可选压力参数，用于分别抽样普通局和高分段。

## 验收

1. 压力函数单调不减，0 分为 100%，2800 分及以上为 127%。
2. 默认调用的波次与旧数值一致。
3. 高压力波次具有更高生命、伤害、密度和脉冲压力。
4. 同一 seed 下，高压力镜像至少不弱于默认镜像。
5. HUD 正确显示当前排位压力。
6. 全部 JavaScript 通过语法检查，小规模平衡抽样可正常完成。

## 实施状态

已接入运行时：

- 排位压力已贯穿 `rankPressure`、尸潮波次、镜像机器人、`Battle` 和 HUD。
- 机器人构筑、遗物和战力评分使用独立随机流，保证同一 seed 下高压力镜像不会因随机数消耗顺序而变弱。
- 默认压力参数保持 100%，旧调用无需修改。
- 全部 JavaScript 语法、压力曲线、波次缩放、机器人强度和 `Battle` 接入测试通过。
- 小规模平衡抽样：100% 压力平均 6.00/12 胜场，127% 压力平均 5.00/12 胜场；高压局更难但仍可取胜。
- 高压对照命令：`node tools/balance.js 3 2 0.5 1.27`。
