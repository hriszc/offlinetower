# 术语表 ·《老皮打僵尸》英文版

本文件是英文翻译的**唯一口径**。多个翻译任务并行时全部以此为准，
保证同一个概念在任何文件里都是同一个词。

## 规则

1. **术语一律照抄本表**，不要自行换同义词（墙永远是 Wall，不写成 Barrier/Fence）。
2. **游戏内文案要短**。界面按汉字宽度排版，英文比中文长得多，能短就短。
   按钮与卡片标题尽量 ≤14 字符，描述尽量 ≤60 字符。
3. **不用句号收尾短标签**（按钮、卡片标题、状态词）；整句描述保留句号。
4. **语气**：冷、干、不卖萌。原文的黑色幽默要保留（如「血肉磨盘」），但不要玩梗过度。
5. **占位符**：`{n}` `{name}` 这类必须原样保留，不要翻译成别的写法。
6. 数字、`×1.28`、`/s`、`·` 分隔符原样保留（`·` 前后保持一个空格）。
