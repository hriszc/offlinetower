# 卡通守家图标

用户要求替换icon，沿用当前全年龄卡通动物与亮灯小屋风格。

- 内置imagegen生成，首页插画`assets/ui-home-scene-v1.jpg`仅作为风格/角色参考。
- 原始母图：`assets/icon-source-v2.png`，完整不透明正方形，不预裁iOS圆角，无文字。
- `node tools/make_icon.js`输出1024、512、192、180、32五种RGB PNG；ffmpeg Lanczos缩放，不依赖浏览器或生成服务。
- `node tools/build_all.js`同步三端与iOS AppIcon；既有manifest内三个网页图标保持齐全。
- 旧`tools/icon.html`保留为历史程序化构图，已标注不作为正式导出源。
