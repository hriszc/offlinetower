# 合作入口与双人房间调整

## 交互

主菜单把“单人守夜”和“合作守夜”放在同一组、同一级按钮中。合作入口只出现在 H5/iOS。合作房间仍可最多加入三人；房间已有两人时，房主可以点“以两人开局”锁定阵容并进入 120 秒备战。第三人先加入则自动按三人开局。进入备战后拒绝新成员，断线者仍凭原房间凭证恢复座位。

原有八个预设昵称的索引保持不变，再追加十六个中英文昵称，服务端只接受有效索引。两人局占前两个座位，分别负责 1–3、4–6 路；三人局继续负责 1–3、4–6、7–9 路。大厅、备战、结果和回放按房间实际人数显示。

## 服务端与结算

增加房主专用 `POST /api/rooms/:code/start`。请求仅在大厅至少两人时生效；重复请求返回当前房间状态。房间状态由 Durable Object 串行更新，第三人加入和房主开局的竞态以先处理的请求为准。准备完成条件改为当前所有成员已准备。确定性结算按实际人数生成尸潮：双人两份、三人三份，均只分配给还活着的成员。现有 12 回合、120 秒准备与奖励阶段、段位规则沿用。

## 验证

覆盖双人开局权限、人数不足、第三人加入竞态、两人全准备、双人结算和下一回合复活；保留三人流程回归。核对 H5/iOS 打包含合作代码，小工具不含联网代码，并检查主菜单在横屏下两个入口同级可见。
