# 全年龄简单卡通界面 Implementation Plan

**Goal:** 按已确认的六界面参考图统一游戏视觉与信息层级，让各年龄玩家更容易辨认角色、理解选择和操作。

**Architecture:** 继续使用现有 Canvas 战场和 DOM 浮层。绘制采用程序化简单卡通，界面共用奶油色面板、夜蓝文字与琥珀按钮；不增加平台分支、不改战斗数值和存档键。中文品牌统一《僵尸在敲门》。

**Tech Stack:** 原生 HTML/CSS/JavaScript、Canvas 2D、现有 Playwright 验证脚本。

### 1. 界面结构与信息层级
- 修改 `js/ui.js`、`index.html`：首页加入程序绘制的守家插画，规则折叠；伙伴图像放大、角色标签、阵容槽和可展开详情；升级奖励与结算保持同一视觉体系。
- 保留按钮 ID、门禁、教学、暂停、键盘操作和所有关键数值的可访问入口。

### 2. 共用样式与移动适配
- 修改 `css/style.css`：奶油面板、圆角卡片、清晰选中/禁用/焦点状态、夜蓝 HUD、琥珀主按钮。
- 检查旋转后的逻辑高度，适配 568×320、844×390、390×844 和桌面；保留滚动与固定确认栏。

### 3. 战场美术
- 修改 `js/render.js`：简化夜景与通道、温暖小屋、友好僵尸、清晰动物轮廓；去除血渍、颗粒、惊吓窥视与重暗角。
- 缓存静态背景和缩略图，不增加每帧资源载入；保持坐标和碰撞规则。

### 4. 文案一致性
- 修改 `js/config.js`：中英文标题与提示一致，短句更清楚；保留价格由商店提供和全部玩法参数。
- 检查主菜单、网页标题、横屏提示、封面与宣传片品牌字符串，只做一致性替换，不重录宣传片。

### 5. 集中验证与交付
- Node 语法检查；已有 gameplay、experience、mobile-layout、i18n、monetize 验证；运行技能游戏浏览器客户端。
- 一次浏览器会话采集六界面及手机/桌面截图，降采样查看，修复实测问题后仅复跑受影响检查。
- `node tools/build_all.js` 重新打包并验证三端核心资源一致；更新 `progress.md`，打开游戏预览。
