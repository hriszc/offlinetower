### 0.2 职业克制（实现数值，`config.js dmgMult`）

| 攻击方职业 | 克制对象 | 伤害系数 |
| --- | --- | --- |
| 枪将 | 骑类怪物 | ×1.25 |
| 骑将 | 刀类怪物 | ×1.25 |
| 刀将 | 枪类怪物 | ×1.25 |

### 0.3 通用战斗机制（实现数值，`engine.js`）

| 机制 | 数值 |
| --- | --- |
| 怒气 | 每次攻击命中每个目标 +4 怒气；满 100 可释放主动技能 |
| 主动技能冷却 | 15 秒/次；**诸葛亮上阵时全队 ×0.85 → 12.75 秒** |
| 暴击 | 全武将通用 12% 概率，暴击伤害 ×1.5（`baseCrit`） |
| 伤害公式 | `伤害 = 有效攻击 × 职业克制系数 × 暴击系数`，向下取整，最低 1（当前无 DEF 减法项，见 §6-13） |
| 有效攻击 | `基础攻击 × (1 + 团队buff + 个人buff)`；基础攻击 = `atk × 星级系数 × (1 + (等级−1)×8%)` |
| 升星系数 | 1 星 1.00 → 2 星 1.50 → 3 星 2.10 → 4 星 2.73 → 5 星 3.28（增幅 50/40/30/20% 递减） |
| 局内升级 | 击杀得经验 `1 + ⌊当前波/3⌋`；升级所需 `3×等级`；每级属性 +8% |
| 人口/地块 | 场上武将上限 6（`popMax=6`），棋盘 7 列 × 5 行，阿斗位于 (6,2) |
| 阿斗血量 | 初始 3 滴，道具「铁壁」+2（5 滴），强化「加固营帐」+1；每掉 1 滴补偿 10 馒头（卖血经济） |

## 1. 武将图鉴（10 名）

> 通用获取/升星规则（每名武将相同，见 §1.0）：**拼字召唤**集齐姓名字牌（2 字武将 2 张 / 3 字武将 3 张）→ 消耗 **20 馒头**召唤；**重复拼出同一武将 → 星级 +1**（上限 5 星）；满星重复拼出 → +5 碎片；星级/等级局外存档保留（`Save.generals`）。字牌来源：征兵抽卡（60% 出字牌/40% 出碎片 ×2）、碎片兑换（10 碎片换 1 字牌）、开局赠字（首局送「赵」「云」；正常局随机赠曹操/赵云/周瑜全套字牌）。

## 2. 主动技能图鉴（10 个，全量）

### 2.1 通用机制（实现数值）

| 规则 | 数值 |
| --- | --- |
| 释放条件 | 怒气 ≥100、技能不在冷却、已上阵、对局未结束 |
| 怒气获取 | 每次攻击命中每个目标 +4（例：赵云一次攻击命中 3 目标 → +12 怒气） |
