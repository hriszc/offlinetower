# 阿斗与赵云 · 武将版（webgame）

对标爆款《赵云与阿斗》的文字合成塔防小游戏复刻——**去掉普通兵种，武将即一切**。
本仓库为可玩的网页版最小闭环（纯前端，无后端依赖，浏览器直接运行）。

设计依据：
- `docs/对标小游戏-阿斗与赵云-设计方案.md`（方案 v1.2，含知乎数值向校准）
- `docs/阿斗与赵云-详细图鉴.md`（图鉴 v1.2，评审 6 点修订：删克制/升星/回血/被动、技能自动释放、武器 8 合 1 精炼、道具仅保留局间一种）

## 运行

无需构建、无需服务器，直接打开 `index.html` 即可（或 `python3 -m http.server` 后访问）。

```bash
python3 -m http.server 8000   # 然后浏览器打开 http://localhost:8000
```

## 测试

```bash
node test/headless.js   # 战斗数值配平 / 技能自动释放 / 局内攻击升级 / 局间道具 / 武器精炼 / 机器人分层
node test/econ.js       # 经济循环：征兵→拼字召唤→布阵→防守（与 game.js 真实逻辑一致）
```

## 架构

| 文件 | 职责 |
| --- | --- |
| `js/config.js` | 全部数值配置：10 武将池、字牌掉率、波次/经济、军衔、地图、机器人分层、局间道具（10）、武器（10 把 × 5 品质） |
| `js/engine.js` | 战斗引擎（纯逻辑无 DOM）：波次生成、POW 约束、武将自动攻击、技能冷却自动释放、局内攻击次数升级、怪物/A斗 |
| `js/game.js` | 主流程状态机：征兵、拼字召唤、布阵、武器掉落/精炼、结算胜负判定（比坚持波数/用时/血量）、广告 |
| `js/ui.js` | DOM 渲染、拖拽布阵、弹窗（结算/局间道具/兵器库）、特效 |
| `js/bot.js` | 拟真人机器人：按军衔分层生成战绩 + 昵称/头像池（本地生成，无真人快照） |
| `js/save.js` | localStorage 存档：军衔积分、蜜獾币、收集、局间道具、武器、体力、每日重置 |
| `js/rand.js` | 加权抽选 / 正态分布 / 洗牌 |
| `index.html` | 单页入口（主菜单/对战/图鉴/帮助） |

## 玩法速览（v1.0 已实现）

- **核心循环**：征兵（抽字牌，成本递增 10/12/14…）→ 拼字召唤（赵+云=赵云，诸+葛+亮=诸葛亮；重复拼出 +5 碎片）→ 布阵（6 人口，7×5 棋盘）→ 防守（30 波，精英/BOSS 波）→ 与机器人对手比谁坚持更久。
- **假 PVP**：对手为按军衔分层本地生成的拟真人机器人（军士约 6 波 → 皇帝约 26 波，8% 失误 / 5% 超常），无真人战绩快照。
- **胜负判定**：阿斗血量归零即败（初始 3 滴）；比坚持波数 → 用时 → 剩余血量。
- **卖血经济**：阿斗每掉 1 滴血补偿 10 馒头；前 4 波发育、第 5 波起馒头转亏，「卖血 vs 硬扛」成为常态决策。
- **无克制/无升星/无回血/无被动**：伤害 = 有效攻击 × 暴击；武将局内按攻击次数升级（需求 15×等级，每级 +8%，配平修正见图鉴 §6-21）；技能冷却结束自动释放（15 秒，无怒气）。
- **局间道具（唯一道具层）**：每局结算后三选一，最多 6 个可替换——锦囊妙计/乱世奸雄/威震华夏/一身是胆/人中赤兔/仁德之君/燕人咆哮/大都督/冢虎之谋/碧眼儿（原被动能力挪入）。
- **武器 8 合 1 精炼**：对局随机掉落上阵武将专属武器（白/绿/蓝/紫/金 5 品质），8 件同名同品质合成高 1 品质，金毕业；无强化。
- **军衔**：11 级（军士→皇帝），胜 +30 / 平 +15 / 败 +5，对手按军衔分层匹配。
- **每日重置**：地图每日轮换（巨鹿/云梦泽/虎牢关）、今日胜率每日清零重算。
- **纯 IAA**：唯一广告点 = 看广告恢复体力（每日 30 点上限、恢复限 5 次/日、每次 +10），无充值入口。
