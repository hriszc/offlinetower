# 《阿斗与赵云》· 武将版（Webgame 最小闭环）

对标爆款《赵云与阿斗》的差异化复刻：**只有武将、无普通兵种**。纯前端网页小游戏，零依赖、零构建、零后端，双击 `index.html` 即可在浏览器运行。

> 开发依据：`docs/对标小游戏-阿斗与赵云-设计方案.md` v1.2（P0 核心玩法最小闭环）

## 如何运行

直接双击 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000    # 然后浏览器打开 http://localhost:8000
```

## 已实现（P0 最小闭环）

- **假 PVP 异步对战**：对手为本地生成的拟真人机器人，按军衔分层生成战绩（军士 5-9 波 → 皇帝 23-29 波，叠加失误/超常发挥），配真人风格昵称/头像/阵容快照；比坚持波数/用时/剩余阿斗血定胜负
- **字谜玩法**：征兵抽字牌（成本 10/12/14…递增）→ 拼字槽凑齐姓名字牌召唤武将（赵+云=赵云；诸葛+葛+亮=诸葛亮）→ 重复拼出转化为碎片
- **开局赠字**：每局开局赠送随机 2 字武将（曹操/赵云/周瑜）全套字牌，保证首将可守；首局固定送「赵」「云」走教学
- **武将体系**：10 名武将（诸葛亮/曹操/关羽/赵云/吕布/刘备/张飞/周瑜/司马懿/孙权）、6 职业（枪/骑/刀/弓/谋/主君）；**无职业克制、无羁绊、无升星、无被动**，构筑深度 = 职业 × 技能 × 站位
- **局内成长（按攻击次数）**：武将每次攻击命中累积成长值，达到阈值自动升级，每级 +8% 攻击/攻速（无升星）
- **技能自动释放**：武将自动攻击积攒怒气，满怒自动释放主动技能（无手动点击交互）
- **局间道具（每局结束 3 选 1）**：武将无被动，改为每局结束后三选一局间道具（最多 6 个、可替换），下一局自动生效（攻击/攻速/暴击/冷却/开局馒头/阿斗上限/精英增伤/怒气获取等）
- **英雄不承伤**：英雄是进攻单位（=塔），无回血/治疗概念；刘备仁德改为纯增益
- **波次塔防**：7×5 棋盘、怪物沿行进犯阿斗（3 滴血）、武将自动攻击 + 满怒自动技能（10 个专属主动技）、每 3 波三选一强化
- **卖血经济**：阿斗每掉 1 滴血补偿 10 馒头；前 4 波收入>消耗，第 5 波起馒头转亏（危机节奏）
- **POW 战力框架**：POW武将=ATK×FRQ×RGE×目标数；波次生成时校验怪物总 POW ≤ 玩家 POW×1.5，超出则削减敌数
- **军衔系统**：11 级军衔（军士→皇帝），胜 +30 / 负 +5 积分，对手按军衔分层
- **纯 IAA**：唯一广告点 = 看广告恢复体力（每日 30 点上限、5 次/日，模拟激励视频播放）
- **每日重置留存**：地图每日轮换（巨鹿/云梦泽/虎牢关 3 张）、今日胜率每日清零、积分/武将收集/蜜獾币保留
- **首局教学**：送「赵」「云」字牌引导拼字→召唤→布阵→作战四步

## 目录结构

```
index.html        入口
css/style.css     水墨文字风样式
js/config.js      数值配置（武将/字牌/波次/经济/军衔/地图/机器人池/局间道具）
js/rand.js        随机工具（加权抽选/正态分布）
js/engine.js      战斗引擎（纯逻辑，不依赖 DOM）
js/bot.js         拟真人机器人生成器
js/save.js        存档（localStorage）/ 军衔 / 每日重置 / 体力
js/game.js        游戏主流程（状态机/征兵/拼字/召唤/强化/结算/广告）
js/ui.js          DOM 渲染/拖拽布阵/弹窗/特效
test/headless.js  node 无头回归测试（战斗数值/机器人分层）
test/econ.js      node 经济循环模拟（征兵-拼字-召唤-防守全链路）
```

## 测试（含断言，失败非零退出码）

```bash
node test/headless.js   # 战斗数值配平 / 机器人分层均值 / 对手军衔分布 / 首将生存
node test/econ.js       # 经济循环（与 game.js 赠字逻辑一致）+ 首局/正常局生存断言
```

> 注：两个测试已注入固定种子 RNG（mulberry32），结果完全确定，CI 可靠。headless 模拟器未模拟三选一强化/怒气运营，6 将 L8 阵容能打到第 30 波终局即证明数值曲线可达；通关依赖玩家运营（每 3 波强化 + 局间道具）。econ 模拟器模拟正常玩家经济运营（粮草/强征军备 + 三选一强化选馒头），未模拟主动卖血与操作优化，断言要求部分局能召唤第 2 将（字牌抽取向已有部分字的武将加权 ×5，保证核心拼字循环单局可达）。

## 与方案的差距（后续 P1）

装备（5 级品质）、道具每日重置、对局内广告救援/时停、排行榜、抖音/微信小游戏平台接入、**蜜獾币消耗出口**（本版蜜獾币仅对局胜利累积展示，无商店消费，经济闭环待 P1 补商店/装备强化）。

**武器系统设计约束（P1）**：武器仅可精炼（8 合 1），不支持强化；本版无武器系统。
